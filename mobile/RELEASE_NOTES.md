## Together Ledger v1.2.9

### 帳本與收支體驗

- 新增共同帳本時，現在可從愛心、生活、交通、支付、記事與娛樂等圖示中選擇，亦可選擇「無」；圖示會同步顯示於 Android 與網頁的帳本列表。
- 收支新增完成後的提示調整為簡潔的「收支已新增。」，不再顯示多餘的跨平台同步說明。
- 網頁版總覽移除分類支出區塊，分類金額與比例保留在分析頁閱讀，讓總覽聚焦近期收支、支付摘要與結算狀態。

### 通知可靠度與安全性

- Android 在登入後會自動重新註冊通知裝置；伺服器投遞 Android 收支通知時會指定正確的通知通道與高優先順序。通知偏好仍可在個人設定自行開關。
- APK 仍僅透過官方 GitHub Release 發布，並附帶 SHA-256 檢查碼；Android 系統會在安裝前顯示確認流程。
