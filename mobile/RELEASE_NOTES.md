## Together Ledger v1.2.8.9

### 同步與使用體驗

- 帳本首頁新增下拉重新整理、最後同步時間與最近可用離線快照提示；連線緩慢或暫時失敗時，可直接重試並繼續查看已同步資料。
- 新增、編輯與移除收支現在會立即更新操作介面，後續資料在背景同步，降低整頁等待與跳動。
- 網頁版同步加入最後同步時間、離線快照與重試同步入口，版本資訊更新為 v1.2.8.9。

### 更新與安全性

- 更新檢查失敗時會清楚顯示網路原因並提供重試按鈕；帳本首頁會主動提示官方新版可用。
- APK 下載完成後會直接開啟 Android 系統安裝確認，並說明首次更新所需的系統來源安裝權限。
- 持續使用官方 GitHub Release、APK SHA-256 檢查碼與 Android 系統安裝確認流程，協助辨識可信更新來源。
