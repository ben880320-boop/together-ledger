## Together Ledger v1.3.6

### 帳本載入與離線回復

- **Android 暫時回應保護**：帳本工作區遇到冷啟動、暫時網路失敗或非 JSON 回應時，會先辨識可重試錯誤、短暫等待後自動重試一次；若仍無法連線，會優先保留可用的離線快照與明確的手動重試入口。
- **安全錯誤訊息**：不再把暫時回應異常誤判為帳本資料遺失；使用者可分辨連線問題與真正的權限／資料錯誤。

### 圖示、說明與更新歷程

- **真正的無圖示**：Android App、Web 與 PWA 選擇「無圖示」後不再顯示預設愛心或錢包圖示。
- **緊湊圖示選擇器**：帳本建立與設定改為可展開的共享 70 項圖示選擇器，保留「無圖示」並降低長清單造成的操作負擔。
- **Wiki 入口**：三端個人設定與外觀設定皆提供 GitHub Wiki 使用說明的直接連結。
- **正確的更新歷程**：App、Web 與 PWA 會依 GitHub tag 擷取對應段落，每個版本只顯示自己的 Release Notes；GitHub v1.3.5 描述亦已修正為單一版本內容。

### 發布與安全性

- Android 版升級為 `versionName=1.3.6`、`versionCode=29`，維持 GitHub Actions 固定受保護簽章與 SHA-256 校驗檔；已安裝 v1.3.5 的官方版本可直接覆蓋更新。
