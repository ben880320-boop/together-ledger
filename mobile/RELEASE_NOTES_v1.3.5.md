## Together Ledger v1.3.5

### 跨平台即時同步

- **SSE 帳本事件流**：Android App、Web 與 PWA 現在以可重連的 Server-Sent Events 接收帳本異動提示；新增、編輯、刪除收支，以及預算、分類、支付方式、儲蓄桶、帳本名稱、圖示、成員與權限異動，會在另一端自動重新取得相關資料。
- **安全同步界線**：事件流僅傳遞帳本游標與異動類型，不會傳送收支金額或收據內容。端點以登入憑證與帳本成員資格驗證，並保留斷線後重連、心跳與手動重新整理路徑。
- **草稿保護延續**：Web／PWA 以防抖快取失效更新，Android 則在背景重新載入工作區；既有開啟中的輸入草稿不會因同步提示被直接覆寫。

### 帳本圖示庫

- 建立帳本與帳本設定共用同一套 **70 個圖示選項**，新增家庭、交通、旅行、理財、生活、健康、學習、工作與自然情境圖示；仍可選擇「無」圖示。

### 發布與安全性

- Android 版升級為 `versionName=1.3.5`、`versionCode=28`，維持 GitHub Actions 固定受保護簽章與 SHA-256 校驗檔。已安裝 v1.3.4 的裝置可在相同簽章下直接覆蓋更新。
