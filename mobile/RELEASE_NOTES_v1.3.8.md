# Together Ledger v1.3.8

## 分類與支付方式圖示選擇器修正

- 修正 Android、Web 與 PWA 的分類／支付方式圖示選擇器未顯示「不使用圖示」與完整圖示庫的問題。
- 新增或編輯分類、支付方式時，固定提供「不使用圖示」入口；選擇後會儲存為真正無圖示，不會改回預設或替代圖示。
- 圖示選擇器預設顯示常用項目；點選展開後可瀏覽完整圖示庫，並可用「車」、「旅行」、「愛心」等中文關鍵字搜尋。

## 安全性與相容性

- Android 版更新為 `versionName=1.3.8`、`versionCode=31`。
- 此 APK 延續官方固定簽章；已安裝官方固定簽章版本的裝置可直接覆蓋更新。
- Release 附有 SHA-256 檢查碼，請僅透過官方 GitHub Release 下載與核對。
