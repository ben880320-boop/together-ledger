# Together Ledger v1.3.10

## 診斷偏好與讀取體驗

- 修正首次開啟「協助改善 App：傳送錯誤診斷」時，讀取與寫入偏好同時發生可能造成儲存失敗的競態問題；伺服器改用原子 upsert。
- 個人設定會在診斷偏好讀取或儲存期間鎖定開關，失敗時顯示明確原因並提供「重新嘗試」入口；預設關閉、明確同意與去識別化資料界線維持不變。
- Android 帳本載入會合併同一時間的重複請求；Web/PWA 優先使用 SSE 同步並減少不必要的重新正規化與快取失效。
- Android 骨架載入改為低干擾淡入淡出回饋，且會尊重「減少動態效果」偏好。

## 發布與安全性

- Android 版升級為 `versionName=1.3.10`、`versionCode=33`。
- APK 持續由 GitHub Actions 使用固定受保護簽章建置，Release 將附帶 SHA-256 校驗檔。
