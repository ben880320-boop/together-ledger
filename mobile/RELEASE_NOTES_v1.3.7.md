## Together Ledger v1.3.7

### 帳本圖示選擇器

- **無圖示固定可見**：Android App、Web 與 PWA 的建立帳本與帳本設定都將「無圖示」置於選擇器最前方，無須先展開或捲動即可選擇。
- **完整圖示更容易找到**：圖示選擇器新增搜尋欄，可用中文關鍵字或表情符號尋找共享圖示庫，例如「愛心」、「車」、「旅行」、「房屋」與「購物」。
- **跨端一致**：Android、Web 與 PWA 都使用相同的共享圖示資料與搜尋規則；選擇「無圖示」後，帳本卡片與切換入口不會顯示預設圖示。

### 發布與安全性

- Android 版升級為 `versionName=1.3.7`、`versionCode=30`，延續 GitHub Actions 固定受保護簽章與 SHA-256 校驗檔。已安裝官方 v1.3.6 的使用者可直接覆蓋更新。
