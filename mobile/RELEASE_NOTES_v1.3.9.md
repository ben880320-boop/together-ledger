# Together Ledger v1.3.9

## Android 帳本設定穩定性修正

- 修正 Android App 進入「帳本設定」時，分類或支付方式圖示選擇器可能因未定義選項常數而導致畫面閃退的問題。
- 圖示選擇器現在會先過濾無效或重複資料，並使用穩定 key；帳本設定另有局部復原畫面，若未來設定元件發生非預期例外，可返回總覽或重新嘗試，不會直接讓整個 App 終止。

## 使用者同意式錯誤診斷

- 在「我的帳本 → 個人設定 → 帳戶與支援」新增「協助回報技術錯誤」開關，**預設關閉**。
- 僅在使用者閱讀說明並明確開啟後，App 才會傳送去識別化的技術診斷資料：平台、App 版本、錯誤代碼、技術訊息與已遮蔽的堆疊資訊。
- 診斷資料不包含帳本、收支、金額、邀請碼、帳號、電子信箱、密碼、憑證或收據圖片；可隨時再次關閉，伺服器也會在寫入前再次驗證同意狀態並遮蔽敏感字串。

## 發布與安全性

- Android 版升級為 `versionName=1.3.9`、`versionCode=32`。
- 此 APK 延續官方 GitHub Actions 固定簽章；已安裝官方固定簽章版本的裝置可直接覆蓋更新。
- Release 附有 SHA-256 檢查碼，請僅透過官方 GitHub Release 下載與核對。
