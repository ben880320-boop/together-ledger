# Together Ledger v1.3.14

## 更清楚的電子信箱帳號操作

- Android App、Web 與 PWA 的註冊、重寄驗證信、忘記密碼與既有帳戶同信箱綁定，皆改為明確、可關閉的浮動提示，避免重要結果被表單內容忽略。
- 忘記密碼只需填入電子信箱；送出後會以不揭露帳戶是否存在的安全提示，說明查看收件匣與垃圾郵件匣、重寄及返回登入的方法。
- 綁定電子信箱與驗證／重設信相關提示，均補上檢查垃圾郵件匣的說明。

## 繁體中文郵件與安全性

- Firebase 用戶端寄送驗證信與密碼重設信前會指定 `zh-TW`，以使用繁體中文在地化範本。
- Firebase Console 可將寄件者固定為「共帳 Together Ledger」，並採用簡短主旨「【共帳】請驗證你的電子信箱」與「【共帳】重設你的密碼」；詳細設定請參閱專案文件。
- Android `versionName=1.3.14`、`versionCode=37`，維持固定受保護簽章與 SHA-256 檢查檔。
