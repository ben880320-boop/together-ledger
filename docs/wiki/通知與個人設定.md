# 通知與個人設定

## Android 通知設定

在 Android App 的「個人設定」開啟收入、支出或每月結算提醒。首次需要通知時，Android 會要求系統通知權限；請在系統設定中允許通知。登入後，App 會自動重新註冊此裝置的通知資訊，讓更換登入狀態、重新安裝或更新後的裝置可重新取得提醒。

| 設定 | 說明 |
| --- | --- |
| 收入提醒 | 共同帳本有收入記錄時通知。 |
| 支出提醒 | 共同帳本有支出記錄時通知。 |
| 金額門檻 | 可只在金額達到指定條件時提醒。 |
| 每月結算提醒 | 可設定每月提醒日，協助檢視結算。 |

> 通知發送仍會受到 Android 系統通知權限、省電模式、網路連線及裝置通知設定影響。若沒有收到通知，請先確認帳本內的提醒開關、Android 系統通知權限與網路狀態，再重新登入或在個人設定儲存一次通知偏好以重新註冊裝置。

## 網頁與 Android 的差異

Android 使用原生通知通道接收提醒；網頁則依瀏覽器能力顯示可用的通知與同步狀態。兩個平台共用帳本資料與通知偏好，但手機系統的通知權限需要由使用者在 Android 裝置上自行允許。

## 個人設定內容

個人設定可從「我的帳本」直接開啟，不必先進入帳本。可以調整暱稱、主題、深淺模式、字體、文字大小、提醒偏好、版本資訊、登出以及帳號刪除。外觀設定會以目前裝置為主；帳本與收支資料則持續跨平台同步。
