# 收支、月曆與結算

## 新增收支

在帳本工作區選擇「新增收支」，依序填寫收支類型、金額、日期、分類、支付方式、付款人與分攤方式。完成後會顯示「收支已新增。」提示，並在背景更新帳本資料。若共同成員在另一個平台查看帳本，重新同步後可看到相同紀錄。

| 欄位 | 用途 |
| --- | --- |
| 類型 | 收入、支出或轉帳。 |
| 金額與日期 | 金額用於統計與結算；日期會影響月曆與月份分析。 |
| 分類與支付方式 | 可由帳本設定新增、編輯、隱藏、恢復或安全刪除。 |
| 付款人 | 記錄哪一位成員先支付。 |
| 分攤方式 | 可使用平均、自訂金額或不分攤。 |

## 更正與刪除

可從總覽的近期收支、完整收支，或月曆日期明細開啟交易，再選擇編輯或刪除。刪除與重要設定修改會出現確認步驟，以降低誤觸風險。

## 月曆與完整收支

月曆使用月份網格顯示每天的收入與支出標記。點選日期可查看當日明細；完整收支則可用「本週」、「本月」與「上月」快速篩選。分析頁集中呈現分類金額、比例與月份比較，因此網頁總覽會維持精簡，專注於近期收支、支付摘要及結算。

## 結算與規劃

總覽提供成員支付摘要與目前結算狀態。規劃頁則可管理月總預算、分類預算、固定收支及獨立的出遊規劃。固定收支到期後可依操作入口同步為實際交易；出遊規劃的日期與預算不會自動併入每月預算。
