# 開始使用

## 註冊與登入

請在 Android App 或網頁登入頁使用電子信箱與密碼註冊。之後無論從哪一個平台登入，都會開啟相同帳號所加入的帳本。請使用自己可持續存取的電子信箱，並避免將密碼或邀請碼公開貼到社群、Issue 或截圖中。

| 你要做的事 | 操作位置 | 注意事項 |
| --- | --- | --- |
| 建立帳號 | 「註冊」頁 | 使用電子信箱與至少可辨識的密碼。 |
| 登入既有帳號 | 「登入」頁 | Android 與網頁版使用完全相同的帳密。 |
| 回到帳本首頁 | 「我的帳本」 | App 重新開啟後會回到此處，不會直接進入舊帳本。 |
| 調整個人資料 | 我的帳本右上角個人設定 | 可設定暱稱、外觀、提醒與帳號選項。 |

## 建立第一個帳本

在「我的帳本」選擇「建立帳本」，填寫帳本名稱，然後挑選一個代表帳本的圖示。可選圖示包括愛心、生活、交通、支付、記事、旅行與娛樂主題；如果不想顯示任何圖示，請選擇「無」。圖示只是視覺識別，不會影響帳本的成員權限、收支計算或資料同步。

建立完成後，系統會建立一個空白帳本與可使用的基本分類、支付方式。請自行新增第一筆收支，不會出現示範交易。

## 加入既有帳本

帳本擁有者會在帳本設定中取得邀請碼。於「我的帳本」選擇「加入帳本」，輸入邀請碼後即可加入。若畫面提示你已加入該帳本，表示不需重複操作；返回「我的帳本」重新整理即可確認是否已顯示於列表。

> 邀請碼等同於加入入口。請只透過可信的私訊或當面方式分享，且不要公開張貼。
