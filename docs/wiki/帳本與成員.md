# 帳本與成員

## 帳本首頁與圖示

登入後會先看到「我的帳本」。此頁可搜尋帳本名稱、重新整理同步資料、檢視最後同步時間、建立帳本或加入帳本。每個帳本卡片會顯示使用者建立時選擇的圖示；未選圖示的帳本則以不帶圖示的卡片呈現，舊帳本仍會保留既有相容顯示。

## 邀請成員

進入帳本後，前往「設定」取得邀請碼。可點擊複製邀請碼，再以安全方式提供給對方。加入成功後，雙方的帳本資料、收支、分類、支付方式與規劃會使用同一份服務端資料。

| 成員操作 | 說明 |
| --- | --- |
| 複製邀請碼 | 由帳本設定取得，供新成員加入。 |
| 檢視成員 | 可查看共同成員與目前角色。 |
| 調整角色 | 擁有者或授權管理者可依畫面選項調整成員權限。 |
| 轉讓擁有權 | 擁有者可先轉讓，再退出帳本。 |
| 退出帳本 | 成員可離開自己的帳本關係；請先確認日後是否仍需要查看歷史資料。 |

## 返回我的帳本

帳本工作區提供「返回我的帳本」入口。使用者可以切換到另一個已加入的帳本，或從首頁進入個人設定；不需要先選取任何帳本才能修改自己的外觀和提醒偏好。

## 安全建議

帳本邀請碼、交易資料與成員名稱皆屬私人資訊。若需要協助排除問題，請提供版本、裝置與重現步驟，並先遮蔽邀請碼、電子信箱、金額及其他個人資訊。
