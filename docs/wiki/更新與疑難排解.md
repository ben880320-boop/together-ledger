# 更新與疑難排解

## 安裝官方 Android APK

請只從 [GitHub Releases](https://github.com/ben880320-boop/together-ledger/releases) 下載 Together Ledger APK。最新版本為 **1.2.9**（versionCode 20）。下載完成後，Android 會顯示系統安裝確認；若首次使用外部 APK，系統可能要求允許目前瀏覽器或檔案管理器安裝應用程式。

| 問題 | 建議處理方式 |
| --- | --- |
| App 顯示有新版本 | 先閱讀更新內容與安全性摘要，再選擇下載。 |
| 下載中斷 | 在更新頁重新嘗試；App 會使用可恢復的下載流程。 |
| 無法安裝 APK | 確認下載來源為官方 Release，並在 Android 系統設定允許目前來源安裝。 |
| 網頁仍顯示舊版 | 使用頁尾的「重新載入最新版本」，讓瀏覽器以新網址重新取得資源。 |
| 沒有看到新帳本或收支 | 確認使用同一組帳密登入，並從我的帳本或帳本頁手動重新整理。 |
| Android 沒有收到通知 | 參閱[通知與個人設定](通知與個人設定)，確認通知開關、系統權限、網路與裝置重新註冊。 |

## 1.2.9 更新摘要

版本 1.2.9 新增可選帳本圖示與「無」圖示選項，精簡收支成功提示，並讓網頁總覽聚焦近期收支、支付摘要與結算。Android 的登入流程會重新註冊通知裝置，伺服器對 Android 收支通知會使用正確通知通道與高優先順序。

## 問題回報

請到 [GitHub Issues](https://github.com/ben880320-boop/together-ledger/issues) 回報問題，並附上平台、版本、預期結果與重現步驟。請勿附上帳本名稱、邀請碼、電子信箱、密碼、通知 token 或完整交易內容。
