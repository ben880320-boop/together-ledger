# 更新與疑難排解

## 安裝官方 Android APK

請只從 [GitHub Releases](https://github.com/ben880320-boop/together-ledger/releases) 下載 Together Ledger APK。最新版本為 **1.3.1**（versionCode 24）。下載完成後，Android 會顯示系統安裝確認；若首次使用外部 APK，系統可能要求允許目前瀏覽器或檔案管理器安裝應用程式。

| 問題 | 建議處理方式 |
| --- | --- |
| App 顯示有新版本 | 先閱讀更新內容與安全性摘要，再選擇下載。 |
| 下載中斷 | 在更新頁重新嘗試；App 會使用可恢復的下載流程。 |
| 無法安裝 APK | 確認下載來源為官方 Release，並在 Android 系統設定允許目前來源安裝。 |
| 網頁仍顯示舊版 | 使用頁尾的「重新載入最新版本」，讓瀏覽器以新網址重新取得資源。 |
| 沒有看到新帳本或收支 | 確認使用同一組帳密登入，並從我的帳本或帳本頁手動重新整理。 |
| Android 沒有收到通知 | 通知、推播裝置註冊及預算門檻提醒目前暫停，版本 1.2.9.2 不會要求通知權限。 |
| 儲蓄桶未於本月立刻入帳 | 系統會在台北時間排程完成後處理到期桶；請確認支付方式仍啟用、日期已到且帳本可用餘額足夠。若餘額不足，歷程會顯示部分分配或略過。 |
| 儲蓄桶無法儲存或暫停 | 若畫面提示其他成員已修改，請重新整理後重新開啟該桶，避免覆寫對方設定。 |

## 1.3.1 更新摘要

儲蓄桶首次達標會顯示慶祝提示，且支援「減少動態效果」偏好。你可封存已達標桶來停止日後自動分配並從主要清單隱藏，既有正式轉存、分配紀錄及操作稽核都會保留；需要時可重新顯示並恢復管理。網頁、PWA 與 Android 的所有新增／編輯表單也會在背景同步或工作區重載時保留未提交草稿。

## 1.3.0 更新摘要

版本 1.3.0 在 Android App、網頁版與 PWA 的「規劃」頁加入儲蓄桶。每個桶可設定目標、每月固定額度、扣款支付方式、日期與優先順序。到期後系統會以冪等的正式轉存交易分配資金；餘額不足時依優先順序部分分配，並保存預定、已分配、不足與狀態歷程。轉存不會計入消費分析，且系統建立的交易不可直接編輯或刪除。儲蓄桶更新與暫停使用版本比對，避免共同成員的異動被靜默覆寫。

## 1.2.9.2 更新摘要

版本 1.2.9.2 暫時停用 Android App 與網頁版的通知設定、通知狀態、推播裝置註冊、收支提醒及月總／分類預算 80%／100% 門檻提醒；伺服器不再建立站內通知或呼叫 Expo 推播。此調整保留帳本、交易、預算與資料表，日後可在 FCM 憑證完整設定後重新規劃啟用。網頁新增或編輯收支時，背景同步不會再覆寫尚未送出的文字、分類、支付方式或分攤選項。

## 1.2.9.1 更新摘要

版本 1.2.9.1 擴充帳本圖示選擇並讓圖示可與名稱一起在帳本設定中修改；新增、編輯及移除收支後會立即更新目前畫面並背景同步。月總預算和分類預算可個別設定 80%／100% 提醒，達標後會建立連至對應支出內容的通知。個人設定新增通知狀態診斷，顯示裝置註冊、最近投遞時間和失敗原因，並可重新整理或在 Android App 重新註冊通知裝置。

## 1.2.9 更新摘要

版本 1.2.9 新增可選帳本圖示與「無」圖示選項，精簡收支成功提示，並讓網頁總覽聚焦近期收支、支付摘要與結算。Android 的登入流程會重新註冊通知裝置，伺服器對 Android 收支通知會使用正確通知通道與高優先順序。

## 問題回報

請到 [GitHub Issues](https://github.com/ben880320-boop/together-ledger/issues) 回報問題，並附上平台、版本、預期結果與重現步驟。請勿附上帳本名稱、邀請碼、電子信箱、密碼、通知 token 或完整交易內容。
