# v1.3.20 Wiki 更新草稿：登入撤銷與帳戶管理

## 已撤銷登入

管理員撤銷非管理員帳戶的登入後，Web、PWA 與 Android 會在下一次驗證時顯示「此裝置的登入已被撤銷」。系統會清除該裝置的記住登入狀態，使用者必須重新輸入已驗證的電子信箱與密碼；**帳本、交易與設定不會因撤銷登入而被刪除**。

這個提示只用於後端確認 `sessionVersion` 不一致的撤銷情境。一般網路中斷、逾時或暫時無法同步會保留既有重試機制，不會被當成撤銷登入。

## 管理頁資料範圍

Web-only 管理頁可依 Firebase 驗證狀態篩選帳戶，並查看最小化資料：帳戶建立時間、最後登入時間、登入方法、衍生的驗證狀態、帳本參與數與擁有數。管理頁不會顯示 Firebase UID、密碼、token、帳本名稱、交易、金額、收據或 IP。

帳戶清單在前景每 30 秒更新一次；搜尋草稿、篩選條件與開啟的對話框不會因更新而重設。刪除帳戶仍需輸入 `DELETE`，且不能刪除自己或其他管理員。

## Firebase 驗證信的中文與樣式

共帳可將使用者帶回 `/login?emailAction=complete`，顯示繁體中文完成說明與重新登入指引。實際驗證信的寄件者、主旨、內容、語言與 Firebase Hosted action page 外觀，必須在 Firebase Console 的 **Authentication → Templates** 與對應 Hosted page 設定中管理；本專案不會、也不能以網頁 CSS 覆蓋該頁面。
