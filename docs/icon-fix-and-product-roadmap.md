# 分類圖示修正與後續產品改善建議

## 本次圖示修正

分類與支付方式過去可能保存了 `◌`、`⌂`、`現`、`卡` 等舊式佔位文字或符號，編輯彈窗便會直接顯示這些原始值。本次改為在讀取、編輯、儲存與清單呈現時統一正規化成表情符號；例如加油會對應 `⛽`、購物對應 `🛍️`、現金對應 `💵`、信用卡對應 `💳`。新增與編輯彈窗也提供橫向快速選擇列，仍保留自行輸入表情符號的彈性。

## 後續優先級

| 優先級 | 建議 | 使用價值 | 實作方向 |
|---|---|---|---|
| P0 | 帳本資料備份與匯出 | 可下載 CSV，避免記錄只能留在 App 內 | 帳本擁有者可匯出交易、分類與結算紀錄；保留繁中欄位名稱 |
| P0 | 新增收支的草稿與快速重複 | 減少每天輸入相同支出的步驟 | 保留尚未送出的表單；在交易列提供「複製為新收支」 |
| P0 | 月度結算提醒 | 讓雙方不會忘記檢查與結清 | 每月最後一天或自選日期顯示帳本內提醒，不自動發送外部訊息 |
| P1 | 收支附件與備註強化 | 保留收據、訂單或照片佐證 | 使用檔案儲存服務，交易最多可附一張壓縮圖片與簡短備註 |
| P1 | 儲蓄目標／共同基金 | 將「記帳」延伸成可執行的共同計畫 | 設定目標金額、期限、已存入金額與進度圖；與出遊預算分開 |
| P1 | 智慧搜尋與篩選 | 快速找出特定日期、金額或付款方式的交易 | 支援日期區間、成員、分類、付款方式及文字關鍵字的組合篩選 |
| P2 | 主畫面可自訂摘要卡 | 讓常用資訊更容易看到 | 可排序顯示本月支出、待結算、最近收支、出遊預算等模組 |
| P2 | 本機生物辨識鎖定 | 在共用裝置上提高隱私 | 以手機指紋／臉部辨識解鎖畫面，不改變既有帳號登入流程 |

> 建議先完成 P0 三項。它們不會增加帳本協作複雜度，卻能直接降低輸入成本、提高資料安心感，並讓「每月一起記帳」形成穩定習慣。
