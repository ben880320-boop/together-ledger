## 頁面一：開始使用

將「加入既有帳本」段落替換為：

```markdown
## 加入既有帳本

帳本擁有者會在帳本設定中取得邀請碼，也可分享 HTTPS 邀請連結或 QR Code。掃描／開啟 HTTPS 邀請時，已安裝 Android App 的裝置會優先開啟 App；未安裝 App、使用 iPhone／iPad 或電腦時，會保留在邀請網頁，讓你先選擇登入或註冊，再以相同帳號安全加入帳本。你也可以在「我的帳本」選擇「加入帳本」並手動輸入邀請碼。若畫面提示你已加入該帳本，表示不需重複操作；返回「我的帳本」重新整理即可確認是否已顯示於列表。

> 邀請碼、HTTPS 邀請連結與 QR Code 都等同於加入入口。請只透過可信的私訊或當面方式分享，且不要公開張貼。
```

## 頁面二：收支、月曆與結算

將「每月結算與規劃」段落替換為：

```markdown
## 每月結算與規劃

總覽提供成員支付摘要與目前結算狀態。結算採「每月快照」：一位成員先提出該月份的未結清差額，另一位成員確認後才會鎖定該月結算。每個帳本在同一月份只會有一筆可版本比對的結算快照，避免多人同時操作時重複提出或靜默覆寫。

鎖定後，該月份不可新增、編輯或刪除會影響金額的收支。若發現需更正舊資料，帳本管理員必須先在總覽選擇「重新開啟本月結算」，完成修正後再重新提出並由另一位成員確認。這能讓已確認的月結算維持可追溯，同時保留必要的更正流程。

規劃頁則可管理月總預算、分類預算、固定收支及獨立的出遊規劃。固定收支到期後可依操作入口同步為實際交易；出遊規劃的日期與預算不會自動併入每月預算。
```
