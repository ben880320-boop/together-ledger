## v1.3.15 更新摘要

登入頁新增「**記住此裝置**」。勾選後，共帳只會以受保護的 Firebase 與 app 工作階段憑證恢復登入，**不會保存、顯示或自動填入密碼**。請僅在個人、受螢幕鎖保護且不會與他人共用的裝置使用。

未勾選時，Web／PWA 只保留目前瀏覽器工作階段；Android 在下次冷啟動時需要重新登入。主動登出、帳戶刪除或 server session version 失效時，系統會清除本機恢復狀態。
