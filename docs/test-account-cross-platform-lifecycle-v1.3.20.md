# v1.3.20 非正式測試帳戶撤銷登入跨端驗收

> 僅限專用、無真實帳本或交易內容的測試帳戶。不得對管理員、使用者本人或任何正式帳戶執行刪除或撤銷驗證。

## 前置條件

1. 使用已完成 Firebase Email 驗證的測試帳戶分別登入 Web／PWA 與 Android，兩端都勾選「記住此裝置」。
2. 以另一個已驗證的管理員帳戶在 Web 管理頁開啟該測試帳戶的安全詳情。
3. 確認管理頁僅顯示登入方式、衍生驗證狀態、建立／最後登入時間與帳本數量，不顯示 UID、密碼、token、帳本名稱、交易、金額或收據。

## 驗收步驟

| 步驟 | 操作 | 預期結果 |
| --- | --- | --- |
| 1 | 管理員選擇「撤銷所有登入」並完成確認 | 顯示進行中狀態；完整成功或「App session 已撤銷、Firebase 待重試」的明確結果。 |
| 2 | 在 Web／PWA 重新發出受保護請求 | 導向登入頁，顯示「此裝置的登入已被撤銷」與資料未刪除說明，且不靜默恢復。 |
| 3 | 開啟 Android 或重新載入工作區 | 顯示相同繁中提示，清除記住裝置偏好與 Firebase 本機身份，不安排靜默恢復。 |
| 4 | 以正確的已驗證信箱與密碼登入 | 可正常取得新的短效 App session；撤銷提示消失。 |
| 5 | 在網路暫時關閉時重新測試一般工作階段失敗 | 不可顯示撤銷提示，也不可清除記住裝置資訊；保留既有的離線／重試流程。 |

## 不執行的操作

- 不刪除任何正式、管理員或使用者帳戶。
- 不以截圖、日誌或測試報告記錄 Email、UID、密碼、token、帳本名稱、交易、金額、收據或 IP。
