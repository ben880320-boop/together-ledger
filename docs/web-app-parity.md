# 網頁與 Android App 對照規格

本文件以 Android App `mobile/app/index.tsx` 為產品行為基準，定義網頁版在登入後應呈現的資訊層級、資料來源及必要互動。兩端皆使用同一個帳號、共同帳本與交易資料；網頁不應建立示範帳本或預設交易。

| 頁面／流程 | Android App 基準 | 網頁端驗收規則 | 資料來源 |
| --- | --- | --- | --- |
| 我的帳本 | 登入後先顯示「我的帳本」，可搜尋、選擇、新增或加入帳本，並顯示同步狀態 | 未選擇帳本時不得直接顯示帳本工作區；帳本卡片、搜尋、同步、建立與加入入口須完整可用 | `ledger.list` |
| 進入帳本 | 點選帳本後進入總覽；返回會回到「我的帳本」 | 帳本工作區提供返回我的帳本控制，且返回後保留帳本列表與搜尋狀態 | `ledger.workspace` |
| 總覽 | 呈現成員支付、近期收支、完整收支入口、分類摘要與結算 | 網頁沿用相同資料與操作次序；新增、編輯、刪除與結算同步刷新 | `ledger.workspace` 與交易 mutations |
| 月曆 | 月標題、星期列、七欄日期格、收入／支出標記與選取日期明細 | 可前後切換月份；日期格依收支顯示收入／支出標記；選取日期即更新明細清單 | `ledger.workspace({ month })` |
| 分析 | 月份摘要、分類占比、成員支付與趨勢 | 網頁沿用同一份 analytics，且提供月份切換 | `ledger.workspace({ month })` |
| 規劃 | 分類預算、固定收支、出遊規劃的建立、編輯與移除 | 網頁所有操作皆使用相同 API、確認步驟與即時刷新 | 規劃 mutations |
| 帳本設定 | 成員／角色、邀請、名稱、轉讓、分類、支付、操作日誌、退出／刪除 | 網頁保留所有現有操作並加入清晰的返回／確認層級 | 設定 mutations 與 workspace |
| 個人設定 | 暱稱、主題、外觀、通知、更新、下載、登出、刪除帳號 | 網頁顯示適用於網頁端的同等設定與 App 下載入口；不把個人設定混入帳本設定 | 個人設定 procedures |

## 手機版視覺驗收

手機寬度 390px 與 430px 的網頁「我的帳本」需使用 App 式安全區、淺藍情境背景、標題區、同步資訊、搜尋欄、帳本卡片及雙欄主要動作。月曆需維持七欄網格，日期和交易標記不可溢出螢幕，選取日期明細須在同一頁面清楚顯示。
