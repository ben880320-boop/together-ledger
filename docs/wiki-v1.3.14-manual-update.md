## v1.3.14 更新摘要

v1.3.14 將 Android App、Web 與 PWA 的註冊、重寄驗證信、忘記密碼與同信箱 Firebase 綁定，統一改為可關閉的浮動提示。忘記密碼流程只需先填寫電子信箱；為保護帳戶安全，畫面不會透露此信箱是否已註冊。寄送後請先查看收件匣，若數分鐘內未收到也請檢查垃圾郵件匣。

Firebase 驗證信與重設信會要求繁體中文範本。管理員應在 Firebase Console 的 **Authentication → Templates** 固定設定寄件者「共帳 Together Ledger」，驗證信主旨「【共帳】請驗證你的電子信箱」，重設信主旨「【共帳】重設你的密碼」。
