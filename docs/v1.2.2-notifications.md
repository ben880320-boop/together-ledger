# Together Ledger v1.2.2：提醒與通知

## 使用者設定

通知全部預設為**關閉**。使用者可在「個人設定 → 提醒與通知」個別控制收入通知、支出通知與每月結算提醒，並設定 1 至 28 日的結算提醒日期。

交易金額門檻以新台幣整數設定。填寫 `0` 代表所有符合類型的交易都提醒；例如填寫 `1,000` 時，只有金額大於或等於 `1,000` 的收入或支出會通知。新增交易的本人不會收到自己的遠端推播，其他帳本成員才會依各自偏好收到通知。

## 推播與隱私

使用者第一次儲存任何開啟的提醒選項時，App 才會向 Android 請求系統通知權限並註冊 Expo 推播 token。系統僅儲存推播 token、平台與啟用狀態；交易通知訊息含帳本名稱、金額與可選備註。若 Expo 回報裝置 token 失效，伺服器會自動停用該 token。

## 每月提醒排程

專案會以每日 **20:00（Asia/Taipei）** 的受驗證排程檢查開啟結算提醒且日期相符的使用者。每個使用者、帳本、月份最多建立一筆結算提醒，避免排程重試或重複執行造成重複通知。提醒會帶入目前待結算金額；若沒有待結算款項，仍會以簡短訊息提示本期狀態。

> 本功能需要手機允許通知。關閉系統層級通知、移除 App 或讓 Android 停用通知頻道後，App 無法強制顯示提醒。
