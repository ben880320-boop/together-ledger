# v1.3.21 驗證紀錄

## 2026-08-27 桌機路由快照

公開首頁 `/` 已呈現固定粉霧品牌視覺，未讀取已登入帳本的情境主題變數。首頁內容、功能介紹、使用情境、FAQ 與頁尾皆可在 1280px 桌機寬度下完整顯示。

登入路由 `/login` 會呈現既有帳本選擇畫面，未出現語法或版面崩潰。管理路由 `/admin` 已顯示撤銷登入稽核面板的時間與結果篩選器，資料載入中不展示目標帳戶、Firebase UID、帳本、收支或憑證資料。

本紀錄僅描述畫面與隱私界線；登入與重新驗證的實際身分流程必須以專用測試帳戶在後續發行驗收中確認，絕不對真實帳戶執行刪除操作。

## 2026-08-27 手機路由快照

公開首頁 `/` 在 375px 寬度下維持單欄版面、可讀的固定品牌色彩與完整內容順序；畫面未出現水平捲軸、截斷 CTA 或因帳本深色／情境主題造成的文字反白問題。

## 2026-08-27 Google 發行前設定

使用者於 Firebase Authentication 的「授權網域」確認正式站點網域已列為 Custom；Google Cloud 的 Android 與 Web OAuth 用戶端類型亦已由使用者畫面確認。GitHub repository Actions secrets 清單已出現 Android 發行流程所需的公開 Web Client ID 設定名稱。此紀錄不保存 Client ID、憑證、token 或使用者資料；正式登入仍須在專用測試帳戶與簽署 APK 中驗證。
