# v1.3.7 GitHub 稽核紀錄

稽核日期：2026-08-22

## Release 說明

使用 GitHub Releases API 逐版檢查 `v1.2.0` 至 `v1.3.6` 共 26 筆正式 Release。每筆 Release 均有且僅有一個 `## Together Ledger v…` 標題，且標題版號與該 Release tag 相同；沒有發現將多個版本更新歷程串接至單一 Release 說明的情況。`v1.2.0` 至 `v1.2.7` 的歷史 APK 檔名為 `app-release.apk`，`v1.2.8` 以後則使用 `together-ledger.apk` 與對應 SHA-256 檔案。

來源：[Together Ledger Releases](https://github.com/ben880320-boop/together-ledger/releases)。

## README 與公開 Wiki

主 README 已列出 v1.3.7／Android versionCode 30、GitHub Releases、正式 Web／PWA 入口與 Wiki 連結。公開 Wiki 首頁在稽核時仍顯示 v1.3.6／versionCode 29；本分支同步了 Wiki 工作副本的首頁與「更新與疑難排解」頁，準備在 v1.3.7 Release 建立後推送至公開 Wiki。

來源：[README](https://github.com/ben880320-boop/together-ledger#readme)、[Wiki](https://github.com/ben880320-boop/together-ledger/wiki)。

## 分支保護

GitHub API 對 `main` 分支保護端點回傳 `404 Not Found`，表示目前沒有套用分支保護規則。建議設定詳見 [BRANCH_PROTECTION.md](BRANCH_PROTECTION.md)。
