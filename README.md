# 共帳 Together Ledger

**Together Ledger（共帳）** 是以「兩人共同生活」為核心的共享記帳服務。使用者可以透過 Android App 或網頁版，以同一組電子信箱與密碼登入同一份帳本資料；建立帳本、加入共同帳本、記錄收支、分攤款項、管理預算及檢視結算，都會同步反映於兩個平台。

> 本專案不會在新帳號或新帳本中建立範例交易、預設帳本或虛構資料。登入後，使用者會先進入「我的帳本」，再自行建立空白帳本或輸入邀請碼加入既有帳本。

| 平台 | 適用情境 | 使用入口 |
| --- | --- | --- |
| Android App | 日常收支、新增交易、相機／相簿掃描收據及行動裝置更新 | [GitHub Releases](https://github.com/ben880320-boop/together-ledger/releases) |
| 網頁版／PWA | 電腦、iOS 或未安裝 App 的使用者；可使用相同帳號、帳本與核心工作區，並加入裝置主畫面 | [Together Ledger 網頁版](https://togetherapp-hdbmsjkf.manus.space) |

## 產品流程

登入成功後，App 與網頁版都會先顯示 **我的帳本**。在此頁面可以搜尋已加入的帳本、檢視同步狀態、建立新的共同帳本，或以邀請碼加入另一個帳本。選擇帳本後，系統會開啟帳本工作區；使用者可以透過總覽、月曆、分析、規劃與設定切換主要功能，收支與個人設定則保留為清楚的工具入口。

| 流程 | 說明 |
| --- | --- |
| 1. 註冊或登入 | 使用電子信箱與密碼建立帳號；Android 與網頁版使用同一帳號。 |
| 2. 建立或加入帳本 | 建立空白共同帳本時可選擇圖示或「無」，也可輸入成員提供的邀請碼加入。 |
| 3. 記錄共同收支 | 選擇付款人、分類、支付方式、日期及分攤規則；可新增、編輯或刪除。 |
| 4. 查看生活財務 | 透過總覽、月曆與分析掌握近期收支、成員支付、分類支出及結算狀態；分類金額與比例集中於分析頁。 |
| 5. 規劃與管理 | 設定分類預算、固定收支、出遊規劃與儲蓄桶，並在帳本設定中管理成員、分類、支付方式及日誌。 |

## 網頁版與 Android App 的資料互通

兩個平台均連到同一個帳號與帳本服務。當一方新增、編輯或移除收支時，目前工作區會立即更新，另一端則透過短週期同步取得相同資料；網頁帳本也會保留最近一次成功取得的可用快照，供網路較慢或暫時離線時閱讀。同步失敗時，畫面會顯示原因並提供重新嘗試的入口。

網頁版依 Android 的行動資訊架構提供「我的帳本」首頁、總覽、月曆、分析、規劃、帳本設定與個人設定。由於裝置能力不同，Android App 提供系統安裝引導與相機流程；網頁則提供檔案選取及下載行為。通知與預算門檻提醒目前暫停。

## 儲蓄桶與每月資金分配

在帳本的「規劃」頁，可建立不限數量的儲蓄桶，例如買車基金、日本旅遊、房屋頭期款或電腦基金。每個桶必須指定一個啟用中的扣款支付方式，並可各自設定目標金額、每月固定分配金額、每月 1 至 28 日的分配日期與優先順序。每日排程會處理已到期且尚未處理的桶；同月份的重試以冪等鍵保護，不會重複轉存。

分配時會依優先順序計算當下帳本可用餘額。若金額不足，較高優先順序的桶可獲得部分分配，系統會在分配歷程保存預定、已分配與不足金額。每一筆成功分配都會建立正式 `transfer` 交易，但不計入收入、支出、月曆消費標記或分析圓餅圖；此交易為唯讀，必須由儲蓄桶本身調整後續設定。儲蓄桶更新與暫停使用版本比對，遇到共同編輯衝突時會提示重新整理後再編輯。首次達標會顯示慶祝提示；可封存／隱藏已達標目標以停止後續分配，而不會刪除既有交易與稽核歷程，並可重新顯示管理。

開啟中的新增或編輯表單會保存自己的輸入草稿。背景同步只更新已提交資料，不會清除或重設尚未儲存的文字、日期、金額與選項。

## 將網頁版加入主畫面（PWA）

Together Ledger 網頁版可安裝為 PWA，安裝後會以獨立視窗開啟，並快取公開介面與靜態資源，讓網路暫時中斷時仍可開啟應用程式與閱讀最近成功同步的帳本快照。為保護帳務資料，Service Worker **不會快取**登入、tRPC 或帳本 API 回應；離線時不可新增、修改或刪除交易，恢復連線後請使用既有同步／重試入口。

| 裝置 | 安裝方式 |
| --- | --- |
| iPhone／iPad | 以 **Safari** 開啟網頁版，按「分享」後選擇「加入主畫面」，再於主畫面開啟共帳。 |
| Android 瀏覽器 | 於公開首頁按「開始使用網頁版」後依瀏覽器提示安裝，或從瀏覽器選單選擇「安裝應用程式」。 |
| 電腦瀏覽器 | 使用網址列或瀏覽器選單提供的安裝圖示；若未顯示，仍可直接用網頁版。 |

當 PWA 偵測到新版時，會顯示「重新載入」按鈕。請先完成正在輸入的資料或保留草稿，再選擇重新載入以套用新版本。

## 下載、安裝與更新 Android App

目前 Android App 版本為 **1.3.1**（versionCode 24）。請僅從本專案的 [GitHub Releases](https://github.com/ben880320-boop/together-ledger/releases) 下載官方 APK，並以 Release 頁面附列的檢查碼確認檔案來源。

| 步驟 | 操作 |
| --- | --- |
| 1 | 於 Android 裝置開啟 [最新 Release](https://github.com/ben880320-boop/together-ledger/releases/latest)，下載 `together-ledger` APK。 |
| 2 | 開啟已下載的檔案，依 Android 系統提示允許目前瀏覽器或檔案管理器安裝應用程式。 |
| 3 | 完成安裝後，以既有電子信箱與密碼登入；不需要重新建立帳本。 |
| 4 | App 偵測到官方新版時，先閱讀版本更新內容與安全性摘要，再依提示下載及安裝。 |

> 安裝 APK 的系統權限只用於完成你主動發起的更新安裝。請勿從非官方網站、聊天訊息或未知來源下載同名 APK。

## 隱私與資料安全

通知、推播裝置註冊與預算門檻提醒目前已暫時停用，Android App 不會要求通知權限。收據掃描只會在使用者主動選擇相機、相簿或檔案時存取該項裝置能力。

帳本、成員、交易與操作日誌只用於共同記帳與結算流程。邀請碼可讓他人申請加入帳本，因此不應公開張貼；同樣地，請勿在公開 Issue、截圖或討論串中附上電子信箱、密碼或交易內容。

## 主要操作說明

| 需求 | 操作位置 |
| --- | --- |
| 建立共同帳本 | 「我的帳本」頁底部的「建立帳本」。 |
| 加入另一個帳本 | 「我的帳本」頁底部的「加入帳本」，輸入擁有者提供的邀請碼。 |
| 新增收支 | 帳本工作區的「新增收支」，填寫類型、金額、日期、分類、支付方式與付款人。 |
| 更正資料 | 從近期收支、完整收支或月曆日期明細開啟交易，再選擇編輯或刪除。 |
| 設定固定收支與預算 | 帳本工作區的「規劃」。 |
| 建立或管理儲蓄目標 | 帳本工作區的「規劃」中的「儲蓄桶」；可查看每月分配歷程。 |
| 管理分類與支付方式 | 帳本工作區的「設定」；已有交易使用中的項目可隱藏，未使用項目可刪除。 |
| 查看誰修改資料 | 帳本工作區的「設定」中的操作日誌。 |
| 調整暱稱與外觀 | 帳本工作區的「個人設定」。 |
| 將網頁加入 iPhone 主畫面 | 網頁公開首頁或個人設定的「加入主畫面」區塊；以 Safari 的分享選單選擇「加入主畫面」。 |
| 下載 Android App | 網頁版個人設定中的 Android App 下載入口，或 GitHub Releases。 |

## 技術與開發

| 部分 | 技術 |
| --- | --- |
| 網頁版 | React 19、Vite、Tailwind CSS、tRPC、Express 與 MySQL／TiDB 資料層。 |
| Android App | Expo SDK 54、React Native 0.81、TypeScript、Expo Router。 |
| 發布 | GitHub Actions 建置 Android APK，並建立或更新對應 GitHub Release。 |

```bash
pnpm install
pnpm exec tsc --noEmit
pnpm test
pnpm build
pnpm exec tsx mobile/scripts/verify-core-flows.mjs
```
