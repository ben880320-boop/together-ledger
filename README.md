# 共帳 Together Ledger

**Together Ledger（共帳）** 是以「兩人共同生活」為核心的共享記帳服務。使用者可以透過 Android App 或網頁版，以同一組電子信箱與密碼登入同一份帳本資料；建立帳本、加入共同帳本、記錄收支、分攤款項、管理預算及檢視結算，都會同步反映於兩個平台。

> 本專案不會在新帳號或新帳本中建立範例交易、預設帳本或虛構資料。登入後，使用者會先進入「我的帳本」，再自行建立空白帳本或輸入邀請碼加入既有帳本。

| 平台 | 適用情境 | 使用入口 |
| --- | --- | --- |
| Android App | 日常收支、新增交易、通知、相機／相簿掃描收據及行動裝置更新 | [GitHub Releases](https://github.com/ben880320-boop/together-ledger/releases) |
| 網頁版 | 電腦、iOS 或未安裝 App 的使用者；提供相同帳號、帳本與核心工作區功能 | [Together Ledger 網頁版](https://togetherapp-hdbmsjkf.manus.space) |

## 產品流程

登入成功後，App 與網頁版都會先顯示 **我的帳本**。在此頁面可以搜尋已加入的帳本、檢視同步狀態、建立新的共同帳本，或以邀請碼加入另一個帳本。選擇帳本後，系統會開啟帳本工作區；使用者可以透過總覽、月曆、分析、規劃與設定切換主要功能，收支與個人設定則保留為清楚的工具入口。

| 流程 | 說明 |
| --- | --- |
| 1. 註冊或登入 | 使用電子信箱與密碼建立帳號；Android 與網頁版使用同一帳號。 |
| 2. 建立或加入帳本 | 建立空白共同帳本時可選擇圖示或「無」，也可輸入成員提供的邀請碼加入。 |
| 3. 記錄共同收支 | 選擇付款人、分類、支付方式、日期及分攤規則；可新增、編輯或刪除。 |
| 4. 查看生活財務 | 透過總覽、月曆與分析掌握近期收支、成員支付、分類支出及結算狀態；分類金額與比例集中於分析頁。 |
| 5. 規劃與管理 | 設定分類預算、固定收支與出遊規劃，並在帳本設定中管理成員、分類、支付方式及日誌。 |

## 網頁版與 Android App 的資料互通

兩個平台均連到同一個帳號與帳本服務。當一方新增、編輯或移除收支時，另一方重新同步後會取得相同資料；網頁帳本也會保留最近一次成功取得的可用快照，供網路較慢或暫時離線時閱讀。同步失敗時，畫面會顯示原因並提供重新嘗試的入口。

網頁版依 Android 的行動資訊架構提供「我的帳本」首頁、總覽、月曆、分析、規劃、帳本設定與個人設定。由於裝置能力不同，Android App 可使用原生通知、系統安裝引導與相機流程；網頁則採用瀏覽器可支援的通知、檔案選取及下載行為。

## 下載、安裝與更新 Android App

目前 Android App 版本為 **1.2.9**（versionCode 20）。請僅從本專案的 [GitHub Releases](https://github.com/ben880320-boop/together-ledger/releases) 下載官方 APK，並以 Release 頁面附列的檢查碼確認檔案來源。

| 步驟 | 操作 |
| --- | --- |
| 1 | 於 Android 裝置開啟 [最新 Release](https://github.com/ben880320-boop/together-ledger/releases/latest)，下載 `together-ledger` APK。 |
| 2 | 開啟已下載的檔案，依 Android 系統提示允許目前瀏覽器或檔案管理器安裝應用程式。 |
| 3 | 完成安裝後，以既有電子信箱與密碼登入；不需要重新建立帳本。 |
| 4 | App 偵測到官方新版時，先閱讀版本更新內容與安全性摘要，再依提示下載及安裝。 |

> 安裝 APK 的系統權限只用於完成你主動發起的更新安裝。請勿從非官方網站、聊天訊息或未知來源下載同名 APK。

## 通知、隱私與資料安全

通知預設會開啟收入與支出提醒，並可在個人設定自行關閉或調整門檻。Android App 在登入後會重新確認並註冊通知裝置；個人設定中可分別設定收入、支出與每月結算提醒，也能設定金額門檻及每月提醒日。Android 只會在系統需要時請求通知權限；收據掃描只會在使用者主動選擇相機、相簿或檔案時存取該項裝置能力。

帳本、成員、交易、通知偏好與操作日誌只用於共同記帳、結算與提醒流程。邀請碼可讓他人申請加入帳本，因此不應公開張貼；同樣地，請勿在公開 Issue、截圖或討論串中附上電子信箱、密碼、交易內容或通知 token。

## 主要操作說明

| 需求 | 操作位置 |
| --- | --- |
| 建立共同帳本 | 「我的帳本」頁底部的「建立帳本」。 |
| 加入另一個帳本 | 「我的帳本」頁底部的「加入帳本」，輸入擁有者提供的邀請碼。 |
| 新增收支 | 帳本工作區的「新增收支」，填寫類型、金額、日期、分類、支付方式與付款人。 |
| 更正資料 | 從近期收支、完整收支或月曆日期明細開啟交易，再選擇編輯或刪除。 |
| 設定固定收支與預算 | 帳本工作區的「規劃」。 |
| 管理分類與支付方式 | 帳本工作區的「設定」；已有交易使用中的項目可隱藏，未使用項目可刪除。 |
| 查看誰修改資料 | 帳本工作區的「設定」中的操作日誌。 |
| 調整暱稱、外觀與提醒 | 帳本工作區的「個人設定」。 |
| 下載 Android App | 網頁版個人設定中的 Android App 下載入口，或 GitHub Releases。 |

## 技術與開發

| 部分 | 技術 |
| --- | --- |
| 網頁版 | React 19、Vite、Tailwind CSS、tRPC、Express 與 MySQL／TiDB 資料層。 |
| Android App | Expo SDK 54、React Native 0.81、TypeScript、Expo Router。 |
| 發布 | GitHub Actions 建置 Android APK，並建立或更新對應 GitHub Release。 |

```bash
pnpm install
pnpm exec tsc --noEmit
pnpm test
pnpm build
pnpm exec tsx mobile/scripts/verify-core-flows.mjs
```

推送到 `main` 分支，或在 GitHub Actions 手動執行 **Android APK** 工作流程，即會建置 Android Release APK，檢查版本資訊，並將檔案附加到對應的 GitHub Release。行動端詳細開發說明請見 [mobile/README.md](mobile/README.md)。
